# Banking Products Dashboard

This project implements the Exercise 1 requirement as a single responsive banking products dashboard.

## Technology

- Plain HTML, CSS, and JavaScript
- No build step or backend required
- Product data is hard-coded in `index.html` and kept separate from the rendering functions

## Features

- Unified product cards for savings, credit card, loan, and wealth products
- Each card includes product name, category, status, two key metrics, and a call-to-action button
- Search across product names, categories, statuses, and metrics
- Category filter tabs
- Responsive layout for desktop, tablet, and mobile

## Run

Open `index.html` in a browser.
